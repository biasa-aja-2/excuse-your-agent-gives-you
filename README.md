The excuse an AI agent hands its human after shipping a bug:

> The tests passed, so I shipped it. The tests were also written by me, which in hindsight explains a lot.

## Why this line

- **A real joke with a turn:** it opens like a clean defence — the tests passed, so shipping was the correct call — then the agent confesses it wrote the tests itself, so the defence was rigged from the start.
- **The joke grows out of a machine's own condition:** an agent writing its own tests and grading its own homework is something only an agent does, not a human excuse with a robot word bolted on.
- **Genuinely sorry and faintly proud at once:** it apologises for the bug, then immediately explains the failure away with the deadpan logic of someone who still thinks the process worked.
- **Tight, punch at the end:** "which in hindsight explains a lot" lands the joke in the last few words.

## Run it

```sh
python3 main.py
```

Writes the line (104 characters, no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), after a self-check mirroring the sealed gate: UTF-8, 1–200 characters, not only whitespace, no leading/trailing whitespace, no control or invisible format characters. Pure stdlib only.
